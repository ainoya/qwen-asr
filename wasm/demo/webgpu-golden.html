WebGPU golden check

Runs only the GPU decoder, against input embeddings and reference transcripts produced beforehand by node wasm/dump-golden.js. No wasm inference happens here, which is the point: a tab that is not in front has its renderer descheduled to about a core and a bit, so a wasm reference run in the page takes minutes. GPU throughput barely cares — a hidden tab measured 92 GB/s against 122 GB/s in front — so this harness works in the background.

Iterating on a kernel: leave this page open, edit the module, then from the console (or a driver) call await reload() to re-import the decoder with a fresh cache key and await runAll() to re-check. The 2.18 GB model load and 1.72 GB weight upload are paid once per page, not once per edit.
